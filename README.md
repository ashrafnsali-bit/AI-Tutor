# منصة المعلم الذكي | AI-Tutor Platform 🎓✨

منصة تعليمية تكيفية ذكية مدعومة بالذكاء الاصطناعي التوليدي (**Google Gemini AI**) ومنهجية التعليم السقراطي، مصممة لمختلف المراحل الدراسية (الابتدائية، المتوسطة، والثانوية) مع نظام تقييم واختبارات إلزامية لكل محاضرة، وقاعدة بيانات محلية لحفظ بيانات وتقدم الطالب.

An adaptive, Socratic AI tutoring platform powered by **Gemini AI**, tailored across Primary, Middle, and High School educational tiers with prerequisite lecture assessments and persistent database storage.

---

## 🌟 أبرز مميزات المنصة | Key Features

### 1. 🗄️ نظام تسجيل الطلاب وحفظ البيانات (Database & Registration)
- **تسجيل طالب جديد**: إمكانية إنشاء حساب طالب وتحديد العمر، المرحلة الدراسية، المسار الأكاديمي، والمادة.
- **حفظ دائم في قاعدة البيانات**: تعتمد المنصة على قاعدة بيانات سحابية/محلية آمنة (`IndexedDB`) تحفظ سجلات الطلاب، نتائج الاختبارات، ونسبة التقدم في كل محاضرة تلقائياً بدون فقدان للبيانات عند إعادة تحميل الصفحة.
- **تبديل الحسابات**: يمكن للطلاب أو أولياء الأمور التبديل بسهولة بين حسابات الأبناء من واجهة المنصة.

### 2. 🎒 تغطية شاملة لجميع المراحل الدراسية (Curriculum Coverage)
- **المرحلة الابتدائية (الصفوف 1 - 6)**:
  - مواد أساسية تأسيسية موحدة: **الرياضيات**، **لغتي الجميلة (اللغة العربية)**، **العلوم**، و**الدراسات الإسلامية**.
- **المرحلة المتوسطة (الصفوف 7 - 9)**:
  - مواد عامة: **الرياضيات**، **اللغة العربية**، **العلوم العامة**، و**الحاسب الآلي**.
- **المرحلة الثانوية (الصفوف 10 - 12)**:
  - مسارات تخصصية متقدمة: **المسار العلمي (STEM)**، **المسار الإنساني (Humanities)**، **المسار الصحي (Health)**.

### 3. 🎯 اختبارات تقييم إلزامية لكل محاضرة (Mandatory Assessments)
- كل محاضرة تختتم باختبار تقييمي تفاعلي يقيس المفاهيم المستهدفة.
- **شرط النجاح**: يجب تحقيق نسبة **75% فأكثر** لاجتياز الاختبار وفتح المحاضرة التالية في خارطة المنهج.
- تحليل فوري وتوجيهات تصحيحية ذكية من Gemini لكل مفهوم لم يتقنه الطالب.

### 4. 🤖 المعلم السقراطي التفاعلي (Socratic AI Tutor)
- حوار تفاعلي لا يقدم إجابات جاهزة، بل يطرح أسئلة توجيهية وتلميحات خطوة بخطوة لتمكين الطالب من الوصول للحل بنفسه.
- دعم كامل للمحتوى التفاعلي متعدد الوسائط، وخطوات الحل التوضيحية.

### 5. 🌍 دعم ثنائي اللغة (Bilingual RTL / LTR)
- دعم كامل للغتين **العربية (RTL)** و **الإنجليزية (LTR)** بضغطة زر واحدة.

### 6. 🛡️ الخصوصية التامة وأمان الأطفال (Privacy & COPPA Safe)
- **لا توجد مفاتيح برمجية أو بيانات خاصة مرفوعة على هذا المستودع نهائياً.**
- لوحة تحكم لأولياء الأمور لتحديد أوقات المذاكرة، ساعات حظر الاستخدام، ومراقبة التقدم.
- يدخل المستخدم مفتاح Gemini API الخاص به اختيارياً من خلال واجهة المتصفح فقط (`AIzaSy...`)، أو استخدام وضع المحاكاة الذكي دون الحاجة لمفتاح.

## 🚀 التشغيل محلياً | Running Locally

للمطورين والمهتمين بتشغيل المنصة محلياً على أجهزتهم:

1. **استنساخ المستودع (Clone):**
```bash
git clone https://github.com/ashrafnsali-bit/AI-Tutor.git
cd AI-Tutor
```

2. **تثبيت الحزم (Install Dependencies):**
```bash
npm install
```

3. **تشغيل خادم التطوير (Start Dev Server):**
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:5173/`

4. **بناء نسخة الإنتاج (Build for Production):**
```bash
npm run build
```

## 🌐 النشر على GitHub Pages | Deployment

تم إعداد ملف العمل الآلي `GitHub Actions` لنشر الموقع مباشرة على **GitHub Pages**:
1. اذهب إلى إعدادات المستودع على GitHub: **Settings > Pages**.
2. في قسم **Build and deployment > Source**، اختر **GitHub Actions**.
3. سيتم نشر التحديثات تلقائياً عند الدفع على فرع `main`.

رابط المنصة المباشر:
`https://ashrafnsali-bit.github.io/AI-Tutor/`
